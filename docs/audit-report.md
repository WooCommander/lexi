# Аудит проекта Lexi — отчёт

Дата: 29.10.2026 · версия 1.1.0 (не выпущена)

Аудит шёл в трёх независимых проходах: безопасность и целостность БД, логика клиента, полнота продукта и качество каталога слов.
Ключевые находки я проверил сам (на временной БД и в коде); часть БД-находок авторы аудита воспроизвели на временной базе.
Живую базу Supabase, реальное устройство и браузер не использовали — всё проверено тестами, сборкой и чтением кода.

**Итог:** критичных проблем (прямая утечка данных или обход защиты без особых условий) не найдено. Серьёзные недоработки были;
самые важные исправлены и покрыты тестами (раздел 1). Остальное — в разделах 2–5, по убыванию важности.

После исправлений: 236 юнит-тестов, 226 проверок БД (RLS, роли, регистрация, демо), типы и сборка — зелёные.

## 1. Исправлено в ходе аудита

### База данных (перезапустите `db/01_schema.sql` → `02_functions.sql` → `03_rls.sql`)

| Что было | Чем грозило | Что сделано |
|---|---|---|
| Ребёнок с родителем мог подключить **второго «родителя»** своим кодом | Второй «родитель» менял цели и запреты, настоящий родитель не мог его убрать — обход нашего же правила «управляет только родитель» | `redeem_invite_code`: управляемому ребёнку подключить другого родителя нельзя |
| Задание можно было создать с **чужой группой** (`group_id`) | Любой «учитель» подсовывал свой набор в чужую группу; новые ученики группы автоматически получали его | Политика проверяет `owns_group`; при подключении по коду берутся задания только владельца кода |
| Код приглашения: 4 знака (~900 тыс. вариантов), `Math.random`, нет лимита | Перебор кодов → подключение к чужой группе, утечка имени учителя | Новые коды: 8 знаков (~8,5·10¹¹) и криптослучайность. **Старые короткие коды работают, пока их не перевыпустят** |
| Коды `eng-test` и `ENG-TEST` могли существовать у двух владельцев | При подключении владелец выбирался случайно (перехват учеников) | Уникальный индекс по `upper(code)` + триггер нормализации |
| Прогресс/история/избранное можно было создать по **любому UUID слова** | Знание UUID открывало чтение чужого слова | В политиках вставки добавлено `can_read_vocab_item` |
| Ребёнок с запретом личных слов создавал набор с `source = 'teacher'` | Обход запрета | `source` разрешён только по роли пользователя |
| Последнего админа можно было понизить `UPDATE`-ом; гонка двух админов | Потеря управления | Триггер на `UPDATE` + advisory-lock |
| `grant_admin` не проверял подтверждение почты | Роль могла достаться тому, кто заранее занял ящик | Только подтверждённая почта |
| `security definer` без `pg_temp` в `search_path` | Теоретическое подмешивание временных таблиц (только при прямом SQL) | `search_path = public, pg_temp` везде |
| Регистрация без почты падала (`name` = null) | Не работали телефон/anonymous-вход | Имя по умолчанию `user` |
| В `03_rls.sql` удалялись только политики с известными именами | Забытая старая политика (OR) молча расширила бы доступ | Перед созданием удаляются **все** политики таблиц |
| Нет индексов под каскады и админ-агрегаты | Медленные удаления и дашборд при росте | Индексы по `review_history(assignment_id, created_at)`, `favorites(vocabulary_item_id)` |

⚠️ Если в вашей базе уже есть коды, различающиеся только регистром, создание уникального индекса упадёт. Проверка перед запуском:
`select upper(code), count(*) from invite_codes group by 1 having count(*) > 1;`

### Клиент

| Что было | Чем грозило | Что сделано |
|---|---|---|
| Офлайн-очередь ответов общая для всех, а «ядовитая» запись блокировала отправку | После смены пользователя ответы нового пользователя **никогда не уходили на сервер**; баннер «ожидают отправки» висел вечно | Записи привязаны к пользователю; чужие ждут владельца; ошибки, после которых повтор бессмысленен (слово удалено, доступ отозван), отбрасываются |
| Запросы без постраничной загрузки (лимит Supabase 1000 строк) | Статистика учителя, слова наборов и прогресс **молча обрезались**: рейтинг и «освоено» занижены, слова пропадали из тренировки | `fetchAllRows` + разбиение длинных списков `id`: прогресс, история, слова наборов, наборы |
| Роли не загрузились (нет сети) → редирект на «домашний» экран и обратно | Пустой экран без объяснения | Если «домой» совпадает с текущим адресом — уводим в профиль |
| При смене аккаунта сбрасывались не все хранилища | Группы, ученики и задания прежнего пользователя видны на общем устройстве | Сбрасываются группы, ученики, задания, очередь тренировки, ошибки |
| «Ещё N слов» после «Повторить ошибки» брал число ошибок | Тренировка из 3 слов вместо выбранных 10 | Запоминается исходный размер |
| «Избранное» обходило дозирование задания и могло дать сотни карточек | Ученик учил ещё закрытые слова; огромная сессия | Закрытые слова исключены, размер ограничен 30 |
| Ввод слова: `й` = `и`, `ї` = `і` | «мий» засчитывалось как «мій» | Диакритику снимаем только у латиницы; кириллица различается |
| Двойной тап «Назначить» в каталоге | Дубли заданий | Защита от повторного нажатия |
| Удаление учителя админом молча уносит слова и прогресс его учеников | Неожиданная потеря данных | Предупреждение в окне подтверждения (см. 2 — M6) |

## 2. Открытые проблемы: база данных

| № | Важность | Суть | Рекомендация |
|---|---|---|---|
| D1 | высокая | **Нет ограничения частоты** на `preview_invite_code` / `redeem_invite_code`. Новые 8-знаковые коды делают перебор нереалистичным, но старые короткие остаются, и ошибка `23505` при создании кода сообщает, что он занят | Перевыпустить старые коды (или принудительно удалить короткие); лимит попыток по `auth.uid()`; срок жизни и счётчик использований |
| D2 | средняя | Учитель видит **материалы другого учителя** через общего ученика (`can_read_word_set`/`can_read_assignment` смотрят на «ученик, которого я вижу») | Учителю показывать только свои задания (`assigned_by = auth.uid()`) |
| D3 | средняя | Каскад: удаление слова/учителя **стирает прогресс и историю всех учеников** по этим словам | Мягкое удаление (`deleted_at`) или `created_by … set null`; удалять слова только без чужого прогресса |
| D4 | средняя | Разрыв связи учитель–ученик оставляет ученика в группах и заданиях учителя | Триггер очистки при разрыве; либо решить, что ученик остаётся в уже назначенном — и написать это |
| D5 | средняя | Хелперы `is_managed_by_parent` и `personal_words_allowed` доступны анониму: по UUID видно, что аккаунт — ребёнок под опекой | Привязать к `auth.uid()`/родственным связям. Осторожно: простой `revoke` от `anon` ломает чтение справочника языков |
| D6 | средняя | Политики вызывают `can_*`-функции построчно → seq scan при росте; админ-агрегаты считают всё на лету (`admin_activity/teachers/popular_words`), без пагинации `admin_list_users` | `(select auth.uid())` в политиках; суточные агрегаты (materialized view/cron); `statement_timeout`; пагинация |
| D7 | низкая | Нет `check` на длину текстов, неотрицательность счётчиков, `start_at ≤ due_at`; ученик может накрутить своё число правильных ответов | Добавить ограничения (отдельной миграцией) |
| D8 | низкая | `languages`: любой учитель/родитель создаёт и переименовывает языки; `allowed_language_ids` без внешних ключей; пара языков слова в наборе не проверяется | Создание языков — только админу; проверка пары на сервере |
| D9 | низкая | `invite_codes`: нет срока жизни; код работает, даже если владелец потерял роль | `expires_at`, `max_uses`, проверка роли при подключении |
| D10 | низкая | Anon получает `all` на таблицы (Supabase по умолчанию); защита только на RLS | `revoke all … from anon`, `grant select on languages` |
| D11 | инфра | Нет нумерованных миграций: `create table if not exists` не меняет существующие таблицы; смена сигнатур `admin_*` потребует `drop function` | Перейти на миграции Supabase CLI |
| D12 | инфра | `05_demo.sql` (с паролем `demo1234` и админом) можно случайно запустить в боевой базе | Защита-флаг; не держать демо-аккаунты в продакшене |

Не воспроизведено (предположения, нужна проверка на реальных данных): производительность политик и агрегатов под нагрузкой.

## 4. Продуктовые несостыковки (по ТЗ и сценариям)

| Важность | Находка |
|---|---|
| высокая | **Родитель не может завести ребёнка:** ребёнок 7–11 лет сам регистрируется (почта, пароль) и вводит код. До ввода кода он считается «взрослым» и сам меняет цели, языки и роли. Нет согласия родителя и возраста. Решение: профиль ребёнка без почты, создаваемый родителем, или обязательный ввод кода сразу после регистрации ученика |
| высокая | **Нет онбординга:** при регистрации не спрашиваются язык изучения и уровень/класс; ученик попадает на пустой экран. Решение: «Что учим? / Какой класс?» → автоподбор 3 тем → первая тренировка из 5 слов |
| средняя | **Ученик не видит задания как задания:** нет срока, «просрочено», «что от меня ждут» — это видят только учитель и родитель |
| средняя | Вход по коду спрятан в «Профиль»; нет ссылки/QR (`/join?code=…`) |
| средняя | Учитель: «Ученики», «Группы» и «Главная» дублируют друг друга; код учителя и код группы лежат на разных экранах; на телефоне «Статистика» убрана в «Ещё» |
| средняя | Нет пути «создать набор → сразу назначить» из `/sets` (есть только со страницы ученика) |
| средняя | Нет уведомлений и отчётов: учитель/родитель узнают о том, что ученик не занимается, только зайдя в статистику |
| низкая | «Рейтинг учеников» в статистике учителя расходится с ТЗ §50 (рейтингов нет) — формулировку лучше сменить на «Кому нужна помощь» |
| низкая | В карточке нет примеров предложений — в каталоге их 0 при поддержке в модели |
| низкая | «Практика» (добор слов без продвижения интервала) никак не объяснена ученику |
| низкая | Родитель: настройки ребёнка спрятаны на 4-й вкладке; маршрут `/languages` доступен, но в меню родителя его нет |

## 5. Каталог слов

Объём: English ≈ 1160, Română ≈ 1030, Українська ≈ 1010 слов, 42 темы (уровни «2–3 класс», «4–6 класс», «Взрослым»).

| Важность | Находка |
|---|---|
| высокая | **Нет примеров** (`пример|перевод`) ни в одном языке — в ТЗ они есть. Слово в контексте — основной способ запомнить |
| высокая | Нет единого стандарта чтения: английский и румынский хранят чтение в данных (разные соглашения), украинский считается правилом. Нет таблицы соответствий и теста, который её применяет |
| средняя | **Артикли и вспомогательные слова даны метаязыком** («определённый артикль») — карточка «слово → ?» неугадываема |
| средняя | Смесь британского и американского английского (`color`/`colour`, `elevator`/`lift`, `vacation`/`holiday`) при британских чтениях |
| средняя | Сомнительные чтения: `your → ё`, `proud → пруд`, `banana → бананэ`; `th` везде «с/з» без различия звонкого и глухого |
| средняя | Многозначные дубли: `orange` (цвет/фрукт), `cook`, `present`, `second`, `break`; ~18 одинаковых русских переводов у разных английских слов (в обратном направлении ответ неоднозначен); в украинском ~50 |
| средняя | Румынский: нет рода/артикля, формы `sunt/este`, `poftim`; мягкие окончания `-i` читаются непоследовательно (`патрузечь` / `зече`); `cincisprezece → чинчспрезече` |
| средняя | Украинский: чтение считается автоматически только для слов с `і и ї є щ ґ ' `; слова вроде `голова`, `гарний`, `дякую` без подсказки; в файле `uk.ts` третье поле у части старых строк — мёртвые данные (экран использует правило) |
| низкая | Дубли слов между темами (`good morning`, `hi`, `thanks`, `лікар`…) — тест проверяет только повторы внутри темы |
| низкая | Нет тем: «Команды учителя» (open your book), «Неправильные глаголы» (ТЗ §8 приводит их как пример набора), «Грамматика» |
| низкая | Темы по классам условные: привязки к конкретной школьной программе нет (из `todo.md`) |

## 6. Недостающие «фишки» (польза / сложность)

1. **Онбординг + подбор набора** (высокая / низкая) — закрывает главный разрыв первого запуска.
2. **Профиль ребёнка без почты + QR/ссылка подключения** (высокая / средняя) — снимает барьер для 2–6 классов.
3. **Задания у ученика** со сроком и прогрессом по набору (высокая / низкая).
4. **Исправление каталога** по разделу 5: примеры, единый стандарт чтения, артикли, дубли (высокая / низкая–средняя).
5. **Напоминания и недельный отчёт родителю/учителю** (высокая / средняя) — push на Android + e-mail.
6. **Офлайн-режим для тренировки** (высокая / средняя–высокая) — кеш слов и прогресса.
7. **Серии дней и значки без рейтингов** (средняя / низкая).
8. **Экспорт набора в CSV/PDF и печатные карточки** (средняя / низкая–средняя) — импорт уже есть.
9. **«Повторение к уроку»** для учителя (средняя / низкая).
10. **Диктант и «слово в предложении»** (средняя / средняя) — озвучка есть, нужны примеры.
11. **«Слово дня» / мини-тренировка на 3 минуты** (средняя / низкая).
12. **Неправильные глаголы и учебные планы по классам** (средняя / средняя).

Что не стоит делать сейчас: AI, распознавание речи, общие рейтинги между учениками.

## 7. Что осталось непроверенным

- Реальная работа на устройстве: озвучка (зависит от голосов на Android), вибрация, вёрстка 360 px, поведение PWA офлайн.
- Производительность БД на больших данных (EXPLAIN не гонялся).
- Юридическая сторона персональных данных детей (согласие родителя, возраст).
- Письмо подтверждения и вход по ссылке на Android (Redirect URL ведёт на веб).

1. Перезапустить в Supabase `01_schema.sql` → `02_functions.sql` → `03_rls.sql` (см. предупреждение про коды в разделе 1), затем при необходимости `05_demo.sql`.

5. Показать каталог носителю языка / учителю (раздел 5).
