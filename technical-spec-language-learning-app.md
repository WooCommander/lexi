# Техническое задание
## Приложение для изучения иностранных слов

## 1. Назначение

Разработать веб-приложение для изучения иностранных слов ребёнком с возможностью подключения родителя и учителя.

Приложение изначально должно поддерживать несколько языков и не быть жёстко привязано к английскому.

На первом этапе предполагается использование для:

- английского;
- молдавского / румынского;
- украинского;
- русского как языка перевода;
- в дальнейшем — любых других языков.

Основная задача приложения:

- изучение новых слов;
- повторение слов;
- изучение слов в обоих направлениях;
- автоматическое повторение сложных слов;
- интервальное повторение;
- сбор статистики;
- назначение слов учителем;
- просмотр прогресса учеником, родителем и учителем.

Первая версия приложения должна быть простой и сфокусированной прежде всего на изучении слов через карточки.

---

## 2. Основной принцип мультиязычности

В коде и базе данных запрещается жёстко использовать поля вида:

```ts
english: string;
russian: string;
```

Вместо этого слово должно храниться как языковая пара.

Например:

```text
English → Russian
apple → яблоко

Russian → English
яблоко → apple

Romanian/Moldovan → Russian
măr → яблоко

Russian → Romanian/Moldovan
яблоко → măr

Ukrainian → Russian
яблуко → яблоко

Russian → Ukrainian
яблоко → яблуко
```

Архитектура должна позволять добавлять новые языки без изменения структуры приложения.

# 6. Ученик

Ученик может:

- изучать слова;
- проходить тренировки;
- повторять слова;
- выполнять задания учителя;
- смотреть собственный прогресс;
- видеть сложные слова;
- добавлять личные слова, если это разрешено;
- видеть свои наборы;
- видеть назначенные наборы;
- выбирать изучаемый язык.

Ученик не должен иметь доступ к статистике других учеников.

# 7. Родитель

Родитель может быть связан с одним или несколькими детьми.

- видеть изучаемые слова;

- создавать собственные наборы;
- добавлять слова ребёнку;
- видеть задания учителя;
- видеть историю активности;
- устанавливать дневную цель;
- выбирать языки, доступные ребёнку.

Учитель получает отдельный рабочий интерфейс.

Учитель может:

- создавать группы учеников;
- подключать отдельных учеников;
- создавать наборы слов;
- указывать язык набора;
- назначать наборы ученикам;
- назначать наборы группам;
- устанавливать дату начала;
- устанавливать срок изучения;
- устанавливать количество новых слов в день;
- смотреть прогресс;
- смотреть статистику по ученику;
- смотреть статистику по набору;
- смотреть статистику по каждому слову;
- видеть сложные слова;
- использовать созданные ранее наборы повторно.

Учитель может вести разные предметы и языки.

Например:

```text

Romanian — Lecția 3
Українська — Тема 2
```

# 22. Интервальное повторение

После правильных ответов использовать интервалы:

```text
1 день
3 дня
7 дней
14 дней
30 дней
60 дней
```

После неправильного ответа:

- уменьшить интервал;
- вернуть слово в текущую или ближайшую тренировку;
- увеличить приоритет слова.

Алгоритм вынести в отдельный сервис:

```text
SpacedRepetitionService
```

Сервис не должен зависеть от Vue или от конкретного языка.

# 47. Row Level Security

RLS должен быть включён для пользовательских таблиц.

Основные правила:

### Ученик

Может:

- читать свои данные;
- читать назначенные ему наборы;
- создавать свою историю тренировок;
- изменять только собственный прогресс;
- читать доступные ему задания.

Не может:

- читать статистику других учеников;
- изменять наборы учителя.

### Родитель

Может:

- видеть данные связанных детей;
- видеть их прогресс;
- создавать родительские наборы.

Не может:

- видеть чужих детей.

### Учитель

Может:

- читать данные связанных учеников;
- видеть статистику своих групп;
- создавать свои наборы;
- назначать задания своим ученикам.

Не может:

- видеть учеников других учителей без установленной связи.

# 53. Главный архитектурный принцип

Приложение должно быть построено не как:

```text
EnglishWord
RussianTranslation
```

а как:

```text
Language A
     ↓
Vocabulary Item
     ↓
Language B
```

То есть ядро системы не знает, изучает пользователь английский, молдавский / румынский, украинский или другой язык.

Это позволит позднее добавлять новые языки без переделки базы данных, статистики и механизма обучения.
